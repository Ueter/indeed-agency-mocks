1. はじめに

本提案書は、Indeed広告運用における管理業務の効率化・自動化を実現するシステムの開発についてご提案するものです。

現在、管理画面上で手作業にて実施されている業務（数値確認・レポート作成・キャンペーン操作等）を、Indeed公式APIを活用したシステムにより段階的に自動化し、運用品質の向上とコスト削減を実現します。

対象アカウント:

  • ETK & Co.
  • ETK JBSA
  • ETK 人材紹介・派遣
  • ETK 直雇用

2. 現状の課題

#課題影響
1クライアントごとに管理画面へログインし数値を確認確認に時間がかかり、即時の判断が困難
2全社合計・横断比較が手作業全体像の把握に遅延が生じる
3レポート作成が手動定期的な工数発生、ヒューマンエラーのリスク
4キャンペーン操作を1件ずつ実施4社×複数キャンペーンの操作に時間を要する
5予算消化状況の把握がリアルタイムでない過剰消化・未消化に気づくのが遅れる
6クライアント情報・請求管理が分散HubSpotと広告データが連動していない

3. ご提案内容（フェーズ別）

Phase 1: ダッシュボード＋定期レポート

Webダッシュボードで全クライアントの運用状況をリアルタイム確認 ＋ 定期レポートをメール/チャットで自動配信

ダッシュボード

  • PC・モバイル両対応（レスポンシブデザイン）
  • ポートフォリオ全体 → アカウント別 → 求人別のドリルダウン
  • 期間フィルタ（今日/今週/今月/四半期/半期）
  • トレンドグラフ・目標との乖離をリアルタイム可視化
  • アラート表示（予算超過、CVR低下、CPA悪化等）

定期レポート自動送付

  • 配信先: 代理店スタッフ
  • 配信頻度: 1日数回（朝・昼・夕、設定可能）
  • 配信手段: メール / Slack / LINE
  • ドリルダウン構造（全社合計 → アカウント別 → キャンペーン別）

主要指標

  • 費用（設定予算 / 消化額 / 消化率 / 着地予測）
  • クリック数・応募数・CVR・CPA
  • 目標値との差分表示
開発期間4週間
開発フィー¥800,000
AWS月額費用¥3,000〜5,000/月

Phase 2: クライアント向け自動レポート生成

クライアント担当者に提出するレポートを自動生成・配信

実現すること

  • 送り先: クライアント担当者
  • 配信頻度: 週次 / 月次 / 四半期（任意設定可）
  • ブランディング対応（ロゴ・フォーマット統一）
  • PDF or Web共有リンクで配信
  • 手作業でのExcel集計が不要に
開発期間3週間
開発フィー¥500,000
AWS月額費用+¥1,000〜2,000/月

Phase 3: 操作の自動化 + HubSpot連携

管理画面での手作業をシステムから一括・自動で実行し、HubSpotとのデータ連携で業務全体を統合

Indeed操作の自動化

操作内容
求人投稿新規求人の一括投稿
求人修正タイトル・説明文・給与・勤務地の更新
キャンペーン作成新規キャンペーンの作成
CPC調整クリック単価の変更
予算設定日次/月次予算の設定・変更
停止・再開キャンペーンの一時停止・再開

HubSpot連携

  • クライアント情報同期
  • 応募→Deal自動作成
  • 広告費→請求管理連動
  • ルールベース自動実行（例: 予算消化率80%超過で自動停止）
開発期間5週間
開発フィー¥1,200,000
AWS月額費用+¥2,000〜4,000/月

Phase 4: AI活用の運用・分析の自動化

蓄積データとAIを活用し、運用判断の自動化・最適化を実現

想定機能

  • CPC・予算自動調整 — パフォーマンスデータに基づく最適入札
  • 異常検知 — 不正クリック疑い・応募急減・コスト急増のアラート
  • 求人原稿最適化 — AIによる原稿の自動生成・改善提案
  • 予算自動配分 — 成果の良いキャンペーンへ自動シフト
  • HubSpotパイプラインデータを含めた真の採用単価最適化
開発期間6週間
開発フィー¥1,500,000
AWS月額費用+¥5,000〜10,000/月

(Phase 5): 他代理店へのサービス展開

本システムで培ったノウハウと仕組みを、他の広告代理店向けにサービスとして展開

  • 運用代行サービス（BPO型）
  • ※ Indeed API契約上、システム自体のSaaS提供には別途交渉が必要
